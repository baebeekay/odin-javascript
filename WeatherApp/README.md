The Modern Forecast (Weather App)
This project is a simple, single-page web application that fetches real-time weather data for any location using the Visual Crossing Weather API. It demonstrates fundamental frontend development concepts, including asynchronous JavaScript (using async/await), DOM manipulation, and dynamic CSS styling based on API data.

✨ Features
Location Search: Easily look up the current weather for any city.

Unit Toggle: Switch temperature and related values between Fahrenheit (°F) and Celsius (°C).

Dynamic UI: The page's background color and emoji change to reflect the current weather conditions (e.g., blue for clear, gray for rain, orange for sunny).

Loading Indicator: Displays a brief "Fetching data..." state during the API request.

Data Processing: Cleans and simplifies the raw JSON response from the API for easy display.
